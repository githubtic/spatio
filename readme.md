# Spatio IO

Spatio IO is a lightweight Java library for:
- spatio-temporal certification
- QR code proof generation
- offline verification

## Installation
```xml
<dependency>
  <groupId>io.spatio</groupId>
  <artifactId>spatio-io-lib</artifactId>
  <version>1.0.0</version>
</dependency>
